# Features

This file is the project feature index for agent-driven work.

## Maintenance Rule

After every implementation prompt, update this file when feature status, scope, implementation notes, or feature prompt guidance changes. Keep entries concise and aligned with the actual repository, not an idealized future architecture.

The end-of-prompt close-out is:

1. Update all affected Markdown files.
2. Update `FEATURES.md` for feature-level changes.
3. Update `CHANGELOG.md` under `Unreleased`.
4. Check `git status --short`.
5. Stage only intended task files.
6. Commit when git delivery is requested or the work is ready for repository history.
7. Push only when explicitly requested.

- Feature 2 Edit Profile opens as a nested Livewire modal only after the owner taps the profile-page action or a completeness deep link. It stays on `/@username`, never posts to the settings route, validates the save payload through `UpdateProfileModalRequest`, saves through `UpdateProfileAction`, refreshes the parent header data after `profile-edit-saved`, dispatches a success toast, and renders as a centered overlay on desktop with a full-screen mobile sheet. When the username changes, the modal dispatches a browser URL replacement event that an Alpine listener handles with `history.replaceState` so `/@username` updates without a page reload. The modal content is a scrollable sectioned form with Basic Information, Profile Media, Social Links, and Privacy sections; Basic Information uses a 50-character display-name counter, cooldown-aware debounced username availability checks enforced through `UpdateProfileAction`, a 160-character auto-growing bio countdown, server-side geocoding suggestions that persist `users.location_lat` and `users.location_lng`, and registration-matched day/month/year date-of-birth selects. Profile Media renders distinct avatar and cover upload panels that sit side by side on desktop, stack on mobile, show current or newly selected previews, and keep avatar removal separate from cover removal. The avatar panel is a circular drop zone with an overlaid hover label, immediate FileReader preview before Livewire uploads, client-side JPEG/PNG/WEBP-only and 3MB validation, permanent Spatie Media Library storage, and queued avatar thumbnail/card image conversions with optimizer support. The cover panel is a roughly 3:1 rectangular drop zone with current cover or gradient preview, FileReader preview, client-side 1200x400 minimum dimension and 5MB validation, an inline vertical drag crop interface that persists `users.cover_photo_position`, and queued cover banner conversion with optimizer support. Social Links renders icon-prefixed fields for website URL, Twitter/X username, Instagram username, Facebook profile URL, and YouTube channel URL; website/Facebook/YouTube validate as URLs on blur, Twitter/X and Instagram normalize to `@username` in the UI, and `UpdateProfileAction` persists canonical public profile URLs in `users.social_links`. Privacy renders only the Account Visibility, Show age on profile, and email-discovery toggles; each is saved immediately through its own authorized Livewire action rather than through the full profile form, with the Private account label stored as follower-gated profile visibility so accepted followers remain supported. Livewire validation failures dispatch the first invalid field target so Alpine can smoothly scroll that field into view and focus it.
