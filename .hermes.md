# Hermes Project Rules

Load `HERMES.md` for the full operating rules.

- Use Laravel 13.x, PHP 8.3+, and Livewire 4.x best practices; this checkout currently runs Laravel 13.12.0, Livewire 4.3.0, and PHP 8.5 locally while Composer requires PHP `^8.4`.
- Use `delegate_task` for subagents on complex Laravel, Livewire, testing, security, database, deployment, and docs work.
- Every subagent must receive complete context and return summary, files inspected, files changed, risks, commands run, tests run, and remaining work.
- Parent Hermes agent verifies, resolves conflicts, and runs final tests where possible.
- Never allow N+1 queries, unloaded relationship access in loops, heavy Livewire `render()` work, large mutable public state, or destructive commands without parent approval.
- Use the Performance, Livewire Component, Eloquent Query, and Deployment checklists in `skills/boost-ai-guidelines.md` before committing Laravel/Livewire performance work.
- Keep filesystem MCP scoped to `/Users/andrejprus/Herd/larapetssocnet`; do not expose secrets or the whole home directory.
