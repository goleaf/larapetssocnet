# Larapetssocnet Memory Guides

Use this skill for project-specific memory workflow. It is intentionally small so agents can find the memory rules without loading every project guide.

Open [memory.md](../../../skills/memory.md) before:

- starting broad or ambiguous work in this repository,
- applying durable user preferences,
- looking up prior decisions, commands, or rollout evidence,
- responding to a request that says remember, save, or keep for future.

Do not write memory unless the user explicitly asks to remember something. When memory is used, cite it in the final response following the active memory citation instructions.
