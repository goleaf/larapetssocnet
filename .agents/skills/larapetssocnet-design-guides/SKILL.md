# Larapetssocnet Design Guides

Use this skill for visual system and layout work. Keep the active design standard singular: Open Design Warm Editorial.

Open:

- [design.md](../../../design.md) for the repository-wide design contract.
- [skills/design.md](../../../skills/design.md) for agent workflow rules.
- [skills/tailwind.md](../../../skills/tailwind.md) for Tailwind/Sass implementation details.
- [skills/accessibility.md](../../../skills/accessibility.md) for WCAG-facing interaction rules.

Never add dark/light switching, runtime visual style switchers, `data-theme` controls, profile theme fields, or alternate palette systems.
